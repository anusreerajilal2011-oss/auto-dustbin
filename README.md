 🗑️ Auto Dustbin

A simple Smart Dustbin made using Arduino IDE and an Ultrasonic Sensors.

The dustbin automatically opens its lid when a person brings their hand close to it.

## 🔧 Components

* Arduino Uno
* Ultrasonic Sensor (HC-SR04)
* Servo Motor
* Dustbin
* Jumper Wires
* Breadboard

## ⚙️ How It Works

The ultrasonic sensor detects the distance of an object.

When an object comes close to the dustbin, the Arduino tells the servo motor to open the lid.

After a few seconds, the lid closes automatically.

## 💻 Software

* Arduino IDE
* Arduino C/C++

## 🚀 How to Use

1. Connect the components.
2. Open the code in Arduino IDE.
3. Connect the Arduino to your PC.
4. Upload the code.
5. Bring your hand near the sensor.
6. The dustbin will open automatically.
